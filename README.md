# Segnalazioni Condominio - PWA

Template installabile per gestire segnalazioni condominiali.

## Funzioni incluse
- Nuova segnalazione con nome/interno
- Zona interessata
- Tipo problema
- Priorità
- Descrizione
- Foto allegata
- Archivio locale
- Stato intervento: Nuova, In lavorazione, Risolta, Archiviata
- Condivisione segnalazione
- Esporta/importa backup JSON
- Contatti amministratore
- Installazione come PWA su telefono e PC

## Come pubblicarla su GitHub Pages
1. Crea una nuova repository su GitHub.
2. Carica tutti i file presenti in questa cartella.
3. Vai su Settings > Pages.
4. Seleziona Branch: main e cartella root.
5. Salva.
6. Apri il link generato da GitHub Pages.

## Come personalizzarla
Apri l'app, vai su Impostazioni e modifica:
- Nome app
- Nome condominio
- Nome amministratore
- Email
- Telefono / WhatsApp

## Nota
Questa versione salva i dati localmente nel browser tramite localStorage.
Per una versione professionale con pannello admin online, database e notifiche Telegram/Email serve un backend.
